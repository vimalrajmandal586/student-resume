# Student Resume

A futuristic, interactive personal resume website created using **HTML5 and CSS3**.

The website is designed with a modern **sci-fi / space theme**, featuring an animated GIF background, glassmorphism cards, neon effects, responsive layouts, and interactive hyperlinks.

## 🌐 Live Website

🔗 **View My Resume:**

---

## 👨‍💻 About the Project

This project is a digital resume created as part of my college web development project.

Instead of creating a traditional resume document, I designed an interactive web-based resume that presents my academic background, technical skills, achievements, interests, and contact information in a futuristic interface.

The website demonstrates the use of HTML and CSS to create a modern and visually engaging webpage.
